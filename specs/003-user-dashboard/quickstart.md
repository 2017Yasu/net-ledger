# Quickstart: User Dashboard

## Running the Dashboard

1.  **Start the application**:
    ```bash
    pnpm dev
    ```
2.  **Log in**: Navigate to `http://localhost:3000/auth/login` and log in with a user account.
3.  **View the dashboard**: After logging in, you will be automatically redirected to the dashboard at `http://localhost:3000/dashboard`.

## Testing

To run the tests for this feature:

- **Unit/Integration Tests**:
  ```bash
  pnpm test
  ```
- **E2E Tests**:
  ```bash
  pnpm playwright test
  ```
