# Code Style and Conventions

## Overview

The project follows standard best practices for TypeScript and React development. Code quality is enforced through ESLint and Prettier.

## Naming Conventions

- **Variables and Functions:** `camelCase`
- **Components and Types:** `PascalCase`
- **Files:** `kebab-case` for general files, `PascalCase` for React components.

## Typing

TypeScript is used throughout the project. All new code should include type annotations.

## Linting and Formatting

- **ESLint:** The configuration is based on `eslint-config-next`.
- **Prettier:** Used for automatic code formatting.

Run `pnpm format` to automatically format and lint the code.
